# 音樂與企業：從巴洛克到印象派 — 單場企業講座（網站）

可瀏覽的講座網站，發布於 GitHub Pages：https://kblab2024.github.io/music-business-lecture/

- **一場獨立、給企業／品牌聽眾**的約 2 小時講座（48 張投影片）。核心命題：**橋是雙向的**——音樂帶動企業（出版／樂器／唱片／場館／品牌），企業扶植音樂（贊助／委創／場館／版稅／行銷）。
- 曲目：全場帶動唱《Funiculì, Funiculà》＋主打聆聽 巴赫《郭德堡變奏曲》、貝多芬第九〈歡樂頌〉；其餘代表曲以 YouTube 名演聆聽。
- 由 `slides.md`／`script.md` 原稿**自動產生**（產生器：`build_site.py`，原稿與工具在 OneDrive 講座資料夾 `音樂與企業_單場講座/`）。
- 每張投影片＝一個區塊（標題・條列・圖片・YouTube 嵌入）；按 **S** 開講者稿；附 **PDF 下載**。
